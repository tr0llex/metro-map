# Архив

Датированные отчёты одного прогона: ревью и визуальная приёмка перед публичным
релизом 1 августа 2026 года.

Они лежат здесь, а не в `docs/`, потому что это **снимки состояния на дату**, а
не документация. Поддерживать их нельзя: любой следующий коммит делает часть
выводов неверной, и отличить живое от протухшего в таком файле невозможно.

Актуальные документы — на уровень выше. Живые инструкции:
[`../VISUAL_QA.md`](../VISUAL_QA.md) — как поднять стенд визуальной приёмки,
[`../QUALITY.md`](../QUALITY.md) — метрики качества схемы.

Открытые задачи из этих отчётов перенесены в [`../../ROADMAP.md`](../../ROADMAP.md).
