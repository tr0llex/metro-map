# Система итеративного поиска оптимальных параметров

## Обзор

Создана система автоматического поиска оптимальных параметров для генерации схемы метро с использованием поиска в глубину и отсечения худших вариантов.

## Файлы

- **`scripts/optimize_params_depth_search.ts`** - основной скрипт оптимизации с поиском в глубину
- **`normalized/best_params.json`** - лучшие найденные параметры

## Как работает

1. **Начальная оценка** - оценивает базовые параметры для получения начального скоринга
2. **Поиск в глубину** - рекурсивно исследует варианты параметров:
   - Приоритетно оптимизируются важные параметры (радиусы колец, раздвижение)
   - Генерируются варианты для каждого параметра
   - Отсекаются варианты, которые хуже лучшего на заданный порог (15%)
   - Продолжается только с лучшими вариантами (beam search, beam width=3)
3. **Оценка каждого варианта**:
   - Применяет параметры к скрипту сборки
   - Пересобирает граф метро
   - Запускает анализ метрик
   - Вычисляет общий скоринг качества схемы
4. **Отсечение** - варианты, которые хуже лучшего более чем на 15%, отбрасываются
5. **Сохранение лучших** - лучшие параметры сохраняются в `normalized/best_params.json`

## Оптимизируемые параметры

### Радиусы колец
- `koltsevayaRadiusScale` - масштаб радиуса Кольцевой линии (6.0-11.0)
- `mccRadiusScale` - масштаб радиуса МЦК (4.0-7.0)
- `bklRadiusScale` - масштаб радиуса БКЛ (4.5-7.5)

### Раздвижение внутри кольца
- `innerMaxRatio` - максимальное расстояние от центра для раздвижения (0.45-0.60)
- `innerBorderRatio` - граница зоны раздвижения (0.95-1.0)
- `innerExplosionFactor` - фактор агрессивности раздвижения (7.0-13.0)

### Оптимизация позиций
- `minDistance` - минимальное желаемое расстояние между станциями (50-65px)
- `criticalDistance` - критически близкое расстояние (20-35px)
- `extremeDistance` - экстремально близкое расстояние (8-15px)

### Итерации алгоритмов
- `smoothingIterations1` - итерации первого сглаживания (6-12)
- `optimizationIterations` - итерации оптимизации позиций (20-35)
- `smoothingIterations2` - итерации финального сглаживания (8-15)

### Масштабирование
- `targetWidth` - целевая ширина карты (2000-2400px)
- `targetHeight` - целевая высота карты (1600-1800px)
- `padding` - отступы (120-180px)

## Использование

```bash
# Запустить оптимизацию
npx ts-node --transpile-only scripts/optimize_params_depth_search.ts
```

Скрипт автоматически:
1. Создает бэкап исходного скрипта сборки
2. Проводит поиск оптимальных параметров
3. Применяет лучшие параметры к скрипту
4. Сохраняет лучшие параметры в JSON

## Дальнейшие улучшения

Система может быть улучшена:

2. Добавить больше параметров для оптимизации

## Примечания

- Скрипт создает бэкап исходного файла сборки перед началом работы
- В случае ошибки можно восстановить из бэкапа
- Поиск может занять время (каждый вариант требует пересборки и анализа)
